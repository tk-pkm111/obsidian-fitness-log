## 取得メモ

- 取得日: 2026-10-01（Notion MCP、読み取りのみ）。53種目すべてのページを個別に取得して中身を確認した。取得できなかったページはない。
- 種目ページ・カテゴリページともに作成日時と最終編集日時がすべて 2026-03-09 06:45 台（数秒の差）に集中している。
- 動画ファイル名は、URLのパスからファイル名部分を取り出してURLデコードし、Unicode NFC に正規化した（macOSからのアップロードで濁点・半濁点が分離した形（NFD）になっていたため）。

- 種目がプログラムでどう使われているかは [01_training-programs](../01_training-programs/) を参照（プログラム側の種目名には `DB`・`HS`・`S/A` などの略語や表記ゆれがある）。
