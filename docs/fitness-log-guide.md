# Fitness Log 使い方ガイド（全ページ）

Obsidian のプラグイン「Fitness Log」の使い方とノートの形式のまとめ。docs/guide の各ページを `npm run docs:bundle` で 1 つにしたもの（直接は編集しない）。

## はじめに / Fitness Log とは

Fitness Log は、筋トレの記録を Obsidian で取るためのプラグインです。ジムでスマホから「▶ 開始 → ■ 終了 → 回数」を押すだけで記録でき、記録は vault の中の Markdown のノートに残ります。

（画像: today-workout.png）

### 3 つの特徴

#### 1. 記録はふつうのノート
記録は 1 日 1 ノート（`Fitness/log/2026-10-25.md`）、種目は 1 種目 1 ノートとして vault に保存されます。プラグインを外しても記録は読めますし、手で直すこともできます。Obsidian Sync を使えば、PC と iPhone で同じ記録を見られます。

#### 2. ジムで迷わない
今日やるパッケージ（例: PUSH A）を開いて ▶ を押すだけ。重量と回数はスクロールで選べ、前回の記録が初期値とヒントに出ます。休憩タイマーは自動で動きます。

#### 3. 事実だけを並べる
ログには、前回の記録・前回比・推移・自己ベストだけを出します。「次は何 kg」のようなアドバイスは出しません。どう伸ばすかは自分で決められます。

### できること

| 画面 | できること |
|---|---|
| 今日 | その日のパッケージで筋トレを記録する。休憩タイマー、記録の修正、コメント |
| パッケージ | 種目の束（PUSH A など）を作る。目標（セット数・回数・休憩）、テンプレート |
| 種目 | 種目のノートを作る・編集する。カテゴリ・器具・記録のしかたは自分で増やせる |
| ルーチン | 「毎週 月・木 は PUSH A」のような予定をカレンダーで見る |
| ログ | パッケージ・種目ごとの推移、自己ベスト、月ごとの一覧 |
| 体組成 | 体重・体脂肪率などの推移と、決めた目標までの差（使う人だけ） |

画面は左上の ☰ で切り替えます。

（画像: menu.png）

> [!note] ベータ版です
> 名前（Fitness Log）と id（`fitness-log`）は仮です。今は BRAT で入れて試せます（「インストール」）。

## はじめに / インストール

Fitness Log はまだコミュニティプラグインの一覧には載っていません。今は **BRAT**（ベータ版のプラグインを入れるためのプラグイン）で入れます。PC でもスマホでも同じ手順です。

### 必要なもの
- Obsidian 1.13.0 以上（PC・iPhone・Android）
- コミュニティプラグインを使える状態（設定 → コミュニティプラグイン → 「制限モード」をオフ）

### 手順
1. 設定 → コミュニティプラグイン → 「閲覧」で **BRAT**（Obsidian42 - BRAT）を探して入れ、有効にします。
2. 設定 → BRAT → **Add beta plugin** を押します。
3. リポジトリに `tk-pkm111/obsidian-fitness-log` と入れて追加します。
4. 設定 → コミュニティプラグイン で **Fitness Log** を有効にします。
5. 左のリボンのダンベルのアイコン、またはコマンド「今日のトレーニングを開く」で開きます。初めて開くと 「最初の設定」 が出ます。

### 更新するとき
設定 → BRAT → **Check for updates** を押します。

- PC とスマホなど、使っている端末は**すべて**更新してください。古い版の端末は、新しい版で書いたノートの一部（新しいカテゴリ・距離の列など）を正しく読めないことがあります。そのときも記録は消さず、書き込みを止めます。

次は → 「最初の設定」

## はじめに / 最初の設定

初めて開くと「Fitness Log をはじめる」が出ます。決めるのは**保存するフォルダ 1 つだけ**です。

（画像: setup.png）

### 保存するフォルダ
入れたフォルダの中に、次の 3 つを作ります（無ければ作ります）。

| フォルダ | 中身 |
|---|---|
| `log` | 記録（1 日 1 ノート） |
| `exercise` | 種目（1 種目 1 ノート） |
| `package` | パッケージ（1 パッケージ 1 ノート。ルーチンもここに書きます） |

「フォルダを別々に選ぶ」で、それぞれ別の場所にもできます。vault にもう記録や種目のノートがあるとき（入れ直したときなど）は、見つかった場所を最初から入れておきます。

### よく使う種目とパッケージの例を入れる
オンのままにすると、66 種目と、プッシュ・プル・脚に分けたパッケージの例（LEGS A・PUSH A・PULL A・LEGS B・PUSH B・PULL B）が入ります。あとで編集・削除できます。すでにある種目・パッケージは足しません。

### 「はじめる」のあと
今日の画面が開きます。まずは 「筋トレを記録する」 へ。

- 「あとで」で閉じても、コマンド「保存先を設定」でいつでもやり直せます。
- 下の「使い方の動画」（42 秒）でも流れを見られます（再生するとインターネットから読み込みます）。

次は → 「筋トレを記録する」

## 今日のトレーニング / 筋トレを記録する

今日の画面で、パッケージ（例: LEGS A）を開いて記録します。ジムでの流れは「筋トレを開始 → 種目の ▶ → ■ → 回数」です。

### 1. 今日のパッケージを出す
- 「ルーチン」 で予定を決めておくと、その日のパッケージが「予定」として出ます。
- 予定が無い日は、下の「＋ パッケージを追加」（右上の ＋ からも）で選びます。

（画像: today-planned.png）

パッケージは種目の名前だけを並べた形で出ます。**▶ 筋トレを開始** を押すと開始の時刻を記録し、種目の一覧が開きます。別のパッケージが筋トレ中でも始められます（先に終える必要はありません）。

### 2. 前回の記録を見る（📈）
種目名のすぐ右の 📈 を押すと、その種目の前回までの記録が出ます。直近 5 回の重量と回数、そのときのセットのコメント、いちばん重かったセット（最高）が見られます。今日の画面の上に出るので、セット中や休憩中でも閉じればすぐ戻れます。**ログで詳しく見る** で、その種目のログへ移れます。

（画像: today-history.png）

### 3. セットを始める（▶）
やる種目の ▶ を押すと、最初のセットだけ「今日は何 kg？」と聞かれます。前回の記録が上に出て、よく使う重量はワンタップで選べます。ほかの重量は下のホイールで選びます（「キーボードで入力」もできます）。

（画像: prompt-weight.png）

セットが始まると、経過時間が数えられます。

（画像: today-set-running.png）

### 4. セットを終える（■）
終わったら ■ を押し、「何回できた？」に答えます。ワンタップの候補は前回の回数のまわりです。

（画像: prompt-reps.png）

記録すると、すぐに休憩のタイマーが動きます。目安（パッケージで決めた休憩）を過ぎると色が変わります。

（画像: today-workout.png）

- 2 セット目からは重量を聞かずに始まり、前のセットの重量を引き継ぎます。変えたいときは行の数字を押して直します（「記録を直す」）。
- いまやっている種目だけが開き、終わった種目は 1 行に、まだの種目は ▶ だけになります。終わった種目を押すと開いて見返せます。
- まだやっていない種目は、左の ⋮⋮ でその日だけ並べ替えられます。混んでいてやらない種目は × でその日の一覧から外せます（パッケージの中身は変わりません）。

### 5. 全体のコメントを書く（💬）
パッケージ名の行の 💬 を押すと、パッケージ全体のコメント（その日の調子・やり方を変えたことなど）を 1 件足せます。書いたコメントは名前の行の下に 1 件 1 行で並びます。

（画像: today-notes.png）

- 見えるのは新しい 2 件だけです。それより前は **前の N 件** にたたまれ、押すと全部を開きます。
- コメントを押すと、その 1 件だけを直したり消したりできます。
- セットごとのコメントは、セットの行の吹き出しです（「記録を直す」）。

### 6. 筋トレを終える
その日のパッケージと単発の種目は、まとめて 1 日の筋トレです。全部終わったら、画面のいちばん下の右の **■ 筋トレを終了** を押します。筋トレ中のものがまとめて終わり、「お疲れ様でした」とその日のまとめ（時間・種目数・セット数）が出ます。

（画像: today-finished.png）

- 終えたパッケージは **記録を見る（2 種目 ・ 3 セット）** にたたまれます。押すと開いて直せます。
- 「ノートを開く」でその日の記録のノートを開けます。
- 続きをやるときは **↻ 筋トレを再開**（今日だけ）。まとめて再開します。
- パッケージごとの終了の時刻は、そのパッケージの最後のセットの終了です（最後にやったものだけ、ボタンを押した時刻）。

### 記録はどこに？
`Fitness/log/2026-10-25.md` のような、その日のノートに書かれます（形は 「ノートの形式」）。

次は → 「記録を直す」

## 今日のトレーニング / 記録を直す

記録した数字は、あとからその場で直せます。

### 数字を押して直す
終えたセットの **重量・回数・開始・終了・休憩** を押すと、その数字だけが入力欄（スマホではホイール）になります。決めれば保存されます。

- 休憩を直すと、そのセットの開始と終了を同じだけずらします。
- 時刻はふだん「時:分」、直すときは秒まで入れられます。

### コメント
セットの右の吹き出しを押すと、そのセットのコメント（感じたこと・フォームのメモなど）を書けます。コメントがあると吹き出しに色が付き、行の下に出ます。パッケージ全体のコメントは、パッケージ名の行の吹き出しで 1 件ずつ足します（「筋トレを記録する」）。

### セットを消す
セットの行の右の **…** を押すと出るメニューの **セット 2 を削除** で消します（確認あり）。番号の丸を押しても同じメニューが出ます。

（画像: today-set-menu.png）

種目を間違えて記録したときは、同じメニューの **この種目を今日から外す** で、その種目の今日のセットもまとめて消せます（「記録した N セットも消えます」と確かめてから）。

### 過去の日
上の ‹ › か日付を押して、ほかの日へ移れます。

- 過去の日は ▶ が「セットを追加」になり、タイマー無しで重量・回数を入れられます（記録し忘れたとき）。
- 先の日は予定だけが見られます。

### パッケージを外す・変える
- パッケージ名の行の × で、その日の予定から外せます。記録があれば一緒に消えることを確かめてから外します。ルーチンの予定だったときは、その日はスキップになります。
- ⋯ の「別のパッケージに変える」で、記録はそのままにパッケージだけを変えられます。

### ノートを手で直してもよい
その日のノートの表を手で直しても、保存すると画面に反映されます。表が読めない形になったときは、プラグインは書き込みを止めて知らせます（記録を消しません）。

次は → 「単発の種目」

## 今日のトレーニング / 単発の種目

どのパッケージにも入っていない種目を、その日だけやるときは「単発の種目」として記録します（ランニング、ストレッチ、思いついた種目など）。

### 記録のしかた
1. 今日の画面の下の **＋ 単発の種目を追加** を押し、種目を選びます（名前を入れて新しく作ることもできます）。
2. あとはパッケージと同じく ▶ と ■ で記録します。
3. 終わったら、画面のいちばん下の右の **■ 筋トレを終了**。パッケージと一緒に、その日の筋トレとしてまとめて終わります。続けるときは **↻ 筋トレを再開** です。

- 単発の種目は、その日のノートでは `## その他` の見出しの下に書かれます。
- ログでは「単発の種目」としてまとまります。

### 有酸素（距離 × 時間）
種目の記録のしかたを「距離 × 時間」にすると、■ を押したときに距離（km）を聞かれます。スマホでは「5 . 2 km」のように 2 列のホイールで選びます。詳しくは 「種目」。

次は → 「パッケージ」

## パッケージとルーチン / パッケージ

パッケージは、1 回のトレーニングでやる種目の束です（例: PUSH A = 胸・肩・三頭の日）。同じ種目でも、やる順番や疲れ具合で扱える重量が変わるので、ログはパッケージの中どうしで比べます。

（画像: packages.png）

### 作る
- **新しいパッケージ**: 名前を決めて、種目を足していきます。
- **テンプレートから追加**: 3 分割（プッシュ・プル・脚）、2 分割（上半身・下半身）、5 分割、全身（3 パターン）から選べます。プログラムごとまとめても、1 つずつでも足せます。

### 編集する
一覧でパッケージを押すと、編集の画面が開きます。

（画像: package-edit.png）

- **種目を追加**: 種目を検索して足します。新しい名前を入れると、その場で種目を作れます。
- **並べ替え**: 左の ⋮⋮ をつかんでドラッグします。
- **外す**: × で外します（確認あり）。外した種目の目標は覚えておくので、もう一度足すと「以前の設定で戻す」を選べます。編集の下の「外した種目」からも戻せます。
- **ルーチンを設定**・**複製**・**削除** は下のボタンから。
- 名前を変えても、過去の記録とはつながったままです。

### 目標（セット数・回数・休憩）
種目の行の ⚙（目標と休憩）を押すと、その種目の目標を決められます。

（画像: package-targets.png）

- **セット数**・**回数**（「6-9」のような幅も可）・**休憩**（休憩の目安。過ぎるとタイマーの色が変わります）・**メモ**（例: ベンチ 60°）。
- 「変更を保存」で保存します。
- 目標は今日の画面には出さず、セットの点線の行（あと何セットか）と休憩タイマーの色にだけ使います。

### セクション（区切り）
設定の「パッケージのセクションを使う」をオンにすると、パッケージの種目を「背中」「腕」のように区切れます。区切りは今日の画面にも見出しとして出ます。

### パッケージはノート
パッケージは 1 パッケージ 1 ノート（`Fitness/package/PUSH A.md`）です。本文は自由なメモに使えます。形は 「ノートの形式」。

次は → 「ルーチン」

## パッケージとルーチン / ルーチン

ルーチンは「いつ、どのパッケージをやるか」の予定です。ルーチンを決めておくと、その日の今日の画面にパッケージが「予定」として出ます。

（画像: routines.png）

### 月のカレンダー
- 月曜始まりのカレンダーに、各日のパッケージを色付きで出します。**塗り = やった**、**枠 = 予定**、取り消し線 = スキップ。
- パッケージ名を押すと、その日の今日の画面へ飛びます（やった日は記録を開いた状態で）。
- 日の空いたところを押すと、下にその日のパッケージと種目の一覧、「この日を開く」「この日はスキップ／戻す」が出ます。

### ルーチンを作る
**＋ 新しいルーチン**（またはパッケージの編集の「ルーチンを設定」）で決めます。

- **毎週**: 曜日を選ぶ（例: 月・木）。2 週ごとなどの間隔も選べます。
- **N 日ごと**: 開始日から 3 日ごと、など。
- **期間**: 始める日と終わる日。
- **有効／無効**: 一時的に止めたいときは無効に。

カレンダーの下に、登録したルーチンの一覧が出ます。

### スキップ
予定の日に休むときは、今日の画面（パッケージ名の行の × か ⋯）かカレンダーで「この日はスキップ」。スキップした予定は「戻す」で取り消せます。

次は → 「種目」

## 種目 / 種目

種目は 1 種目 1 ノート（`Fitness/exercise/ケーブルYレイズ.md`）です。設定はノートのプロパティに、フォームのコツや参考動画は本文に自由に書けます。

（画像: exercises.png）

### 一覧
- 上の検索で名前・別名から探せます。
- カテゴリのチップで絞り込めます。✎ でカテゴリの一覧を編集できます。
- 行のノートのアイコンで種目のノートを開き、🗑 で削除します（ノートはゴミ箱へ。過去の記録は残ります）。
- 使わなくなった種目はアーカイブにすると一覧から隠れます（「アーカイブも表示」で見られます）。

### 新しい種目
**＋ 新しい種目** で名前を入れると、「どの部位の種目ですか？」と聞かれます。部位を押せばその場で作れます。器具や記録のしかたは、あとから編集で決められます。

### 編集
一覧で種目を押すと編集画面が開きます。

（画像: exercise-edit.png）

| 項目 | 内容 |
|---|---|
| 名前 | 変えるとノートの名前も変わり、前の名前は「別名」に残ります。過去の記録とはつながったままです |
| カテゴリ | プッシュ・プル・脚・肩・腕・体幹・有酸素・その他（自分で増やせます） |
| 器具 | マシン・ケーブル・スミス・バーベル・ダンベル・自重・バンド・その他（自分で増やせます） |
| 記録のしかた | 何を記録するか（下の表） |
| 片側種目 | 左右それぞれ行う種目 |
| 別名 | 略称や別の呼び方（1 行に 1 つ）。検索と記録の照合に使います |

### 記録のしかた
| 記録のしかた | ▶ のとき聞くこと | ■ のとき聞くこと | 向いている種目 |
|---|---|---|---|
| 重量 × 回数 | 重量 | 回数 | ふつうの筋トレ |
| 回数のみ | — | 回数 | 自重（懸垂・ディップスなど） |
| 時間のみ | — | — | プランク・ストレッチ |
| 重量 × 時間 | 重量 | — | ファーマーズウォークなど |
| 距離 × 時間 | — | 距離（km） | ランニング・バイク |

重量・回数・距離・時間を組み合わせて、新しい記録のしかたも作れます（選ぶ欄の「＋ 新しい記録のしかた…」）。

### 選択肢を自分で変える
カテゴリ・器具・記録のしかたの一覧は、選ぶ欄の「＋ 新しい…」でその場で足せ、「一覧を編集…」（設定の「種目の選択肢」、種目の画面の ✎ からも）で名前の変更・並べ替え・削除ができます。

- 名前を変える・消すと、使っている種目のノートも書き直します。
- 一覧は vault の設定ノート（`Fitness Log 設定.md`）に保存するので、ほかの端末とそろいます。

次は → 「ログ」

## ログ / ログ

ログでは、記録の推移を見返します。同じ種目でもパッケージ（やる順番・その前の疲れ）で扱える重量が変わるので、まずはパッケージの中どうしで比べます。

上のタブで **パッケージ／種目／月ごと** を切り替えます。

### パッケージ
パッケージの色のチップを選ぶと、そのパッケージの概要と、今の並び順の種目が出ます。

（画像: log-package.png）

- 概要: やった回数・最近 4 週の回数・最後の日と、1 回ごとの合計ボリューム（重量 × 回数）の棒。
- 種目の行: 前回のセット・前回比（+1 回、+2.5 kg など）・推移の小さな線・★ 自己ベスト。
- 途中から加えた種目は「9/14 から」のように出ます。外した種目やその日だけ足した種目は「今の内容に無い種目」に記録が残ります。

### 種目の推移
種目の行を押すと、そのパッケージの中での推移が開きます。

（画像: log-exercise.png）

- 指標を切り替えられます: **推定 1RM**・**最大重量**・**ボリューム**（自重の種目は回数、時間の種目は時間、距離の種目は距離）。
- グラフはなぞる・タップでその日の値。同じ点をもう一度押すとその日の画面へ。
- 下に記録の表（前回比と、その時点の最高を超えた回に ★）。
- 「ほかのパッケージと比べる」で、別のパッケージの線を点線で重ねられます。「この種目をすべてのパッケージで見る」で種目のタブへ。

### 種目
種目を検索して、パッケージごとの線で推移を見ます。凡例を押すとその線を隠せます。

### 月ごと
日ごとの一覧です。押すとその日の画面へ。

### アドバイスは出しません
ログに出すのは、記録・前回比・推移・自己ベストという事実だけです。「上げどき」「停滞」「次は何 kg」のような判断はしません。

### 表で見る（Bases）
設定 → データ → 「記録の一覧表（Bases）を作る」（コマンドでも）で、記録のノートを表で見る `.base` ファイルを作れます（Obsidian の Bases）。

次は → 「体組成」

## 体組成 / 体組成

体重・体脂肪率・筋肉量などの体組成を記録して、推移と、自分で決めた目標までの差を見られます。使う人だけがオンにするページです。

### オンにする
設定 → Fitness Log → 体組成 → **体組成を記録する** をオンにすると、☰ のメニューに「体組成」が出ます。オンにすると「体組成の保存先」と「体組成の項目」の行も出ます。

（画像: settings-body.png）

オン・オフ・項目・目標は vault の設定ノートに書くので、ほかの端末でも同じになります。

### 画面の上
- 開くといつも**最新の測定**が出ます。‹ › で前後の測定へ。
- 📅 で測った日のカレンダー。色の付いた日を押すとその日の測定へ、右下の「最新」で最新に戻ります。
- **＋ 測定を記録** で手で入れられます。

（画像: body-calendar.png）

### 全身
項目ごとに丸を並べます。丸の下は前回からの差です（色は付けません。増量中の人には増えるのが良いことなので）。丸を押すと、その段のすぐ下に詳しいパネルが開きます。

（画像: body-whole.png）

- **前回から**・**初回から**・**目標まで**（目標があるとき）。
- 期間（1か月・3か月・半年・1年・すべて。最初は 1か月）を選んで推移のグラフを見ます。目標があれば目標の値に点線を引きます。
- グラフの点を 2 回押すと、その測定を見ます。
- 下の「項目を編集」で、丸に出す項目と並び・単位を決めます。「ノートにある項目」からも足せます。

### 部位別
人の形の周りに、体幹部・左右の腕・左右の脚の値を並べます。上のチップで項目（筋肉量・脂肪率など）を切り替え、「左右の差」も出します。腕か脚を押すと、左と右の 2 本の線で推移を見られます。

（画像: body-parts.png）

部位別の値は「左腕 筋肉量」のような名前で記録すると出ます（「ほかのアプリから取り込む」）。

### 目標
全身の項目に目標の値を決めると、今の値からあとどのくらいかを出します。

（画像: body-goals.png）

- 増やす目標は **青・▲・「増」**、減らす目標は **橙・▼・「減」**。
- バーは、目標を決めた日の値から目標までの進み具合です。数の小さいほうが左で、減らす目標は右から左へ伸びます。目標から離れたときは空のままです。
- 丸の縁にも同じ進み具合が出ます（増やす目標は時計回り、減らす目標は反時計回り）。
- 「あと 8.0 % 減」は、今の値から目標の値までの差です（体脂肪率なら、その値を 8.0 下げる意味）。

### 測定を記録する（手で入れる）
**＋ 測定を記録** で、日付・時刻と、丸に出している項目を入れます。薄い数字は前回の値で、空欄の項目は記録しません。部位別はたたんである欄から入れられます。

（画像: body-record.png）

同じ日にもう一度記録すると、入れた項目だけを書き換えます。

### 出さないもの
体組成計の評価（「標準」「少ない」など）・標準範囲・体型の判定は出しません。測った値と、その差と、自分で決めた目標までの差だけです。

次は → 「ほかのアプリから取り込む」

## 体組成 / ほかのアプリから取り込む

体組成計のアプリやヘルスケアから自動で値を取っている人は、その仕組み（スクリプトや AI エージェント）で、次の形のノートを書けば体組成のページに出ます。プラグインは特定の機器やアプリの形式は読まず、このノートの形だけを読みます。

### ノートの形
保存先は設定の「体組成の保存先」（既定は種目フォルダの隣の `body-composition`）。**1 回の測定で 1 ノート**、名前は測った日（`2026-10-22.md`）です。

```markdown
---
時刻: "07:11"
体重: 66.7
体脂肪率: 18.5
筋肉量: 51.2
内臓脂肪レベル: 7
左腕 筋肉量: 2.9
右腕 筋肉量: 2.9
---
（本文は自由。プラグインは触りません）
```

- **プロパティの名前が項目名**（日本語でよい）、**値は数字だけ**（単位は書かない。「67.8 kg」ではなく 67.8）。
- 重さ（kg）の項目は kg で書きます（画面では設定の重量の単位に合わせて出します）。
- `時刻` は任意（`"HH:mm"`）。
- **部位別**は「部位 + 半角スペース + 項目」。部位は **体幹部・左腕・右腕・左脚・右脚** の 5 つです（例: `体幹部 脂肪率`）。
- 測っていない項目は書かない。
- 「標準」のような文字の値・評価・評価値・左右バランスの文章・体型は書かなくてよい（書いても読みません）。
- 同じ日にもう一度測ったら、そのノートを書き換えます（入れる項目だけを上書きし、本文は残す）。

### 同じフォルダに置いてよいもの
プラグインが読むのは**名前が日付のノートだけ**です。全部の測定をまとめた一覧のノートなど、日付以外の名前のノートは同じフォルダに置いても読みません。逆に、体組成ではない日付の名前のノートはこのフォルダに置かないでください。

### 項目を画面に出す
最初に丸で出るのは体重・体脂肪率・筋肉量の 3 つです。ほかの項目は、全身の「項目を編集」→「ノートにある項目」の ＋ で足せます。よく使う名前（体重・BMI・基礎代謝量・体内年齢・推定骨量・体水分率・筋質点数 など）は単位も自動で入ります。

### 目標は画面から
目標はプラグインの画面（目標のタブ）で決めます。設定ノートに書かれるので、自動取得の仕組みでは書かなくて大丈夫です。

### AI エージェントに頼むときの例
```text
体組成の測定を取得したら、Obsidian の Fitness Log プラグインが読む「体組成のノート」も書いてください。
- 保存先: <体組成の保存先>/YYYY-MM-DD.md（測った日。1 回の測定で 1 ノート）
- 同じ日付のノートがあれば新しく作らず、書くキーだけを上書きする（ほかのキーと本文は残す）
- frontmatter:
  - 時刻: "HH:mm"（ダブルクォートで囲む）
  - 測定値: 「項目名: 数値」。項目名は日本語のまま、値は数値だけ（単位・引用符なし）
  - 部位別は「左腕 筋肉量」のように部位と項目を半角スペースでつなぐ（部位: 体幹部・左腕・右腕・左脚・右脚）
- 書かない: 文字の値（「標準」など）、名前に「評価」を含む項目、体型・目標体型、値の無い項目
- このフォルダには、体組成のノート以外に日付の名前のノートを作らない
```

設定 → コミュニティプラグイン → **Fitness Log**（または ☰ のメニューの「設定」）で開きます。

（画像: settings.png）

### 保存先
| 設定 | 既定 | 内容 |
|---|---|---|
| 記録の保存先 | `Fitness/log` | 記録（1 日 1 ノート） |

### 記録

|---|---|
| 重量の単位 | kg／lb。表示と入力の単位です（ノートには kg で保存します） |
| 重量の刻み | 重量を選ぶときの刻み（例: 2.5）。1.25 などもできます |
| 休憩タイマーを表示 | セットの後の経過時間を出します。休憩の目安を過ぎると色が変わります |
| 起動時に今日の画面を開く | Obsidian を開いたときに今日のトレーニングを出します |
| パッケージのセクションを使う | パッケージの種目を「背中」「腕」のように区切れます |

### 種目の選択肢
カテゴリ・器具・記録のしかたの一覧を編集します（「種目」）。

### 体組成
「体組成を記録する」のオン・オフ、保存先、丸に出す項目（「体組成」）。

### データ
- **よく使う種目とパッケージの例を入れる**: 足りないものだけを追加します。今あるものは変えません。
- **記録の一覧表（Bases）を作る**: 記録を表で見られる `.base` ファイルを、記録の保存先に作ります。

### コマンド
コマンドパレットから使えます: 今日のトレーニングを開く／トレーニングログを開く／体組成を開く（体組成を記録するときだけ）／保存先を設定／記録の一覧表（Bases）を作る。

## データと設定 / 複数の端末で使う

PC と iPhone のように複数の端末で使うときは、Obsidian Sync（など vault を同期する仕組み）で vault をそろえます。

### そろうもの（vault のノート）
記録・種目・パッケージ・ルーチン・カテゴリなどの一覧・体組成の測定と設定は、すべて vault のノートに書くので、**プラグインの設定を同期していなくても**端末間でそろいます。

| 何 | どこ |
|---|---|
| 記録 | 記録の保存先の日付のノート |
| 種目 | 種目の保存先のノート |
| パッケージ・ルーチン | パッケージの保存先のノート |
| カテゴリ・器具・記録のしかた・体組成のオン/オフ・項目・目標 | 設定ノート（種目フォルダの隣の `Fitness Log 設定.md`） |
| 体組成の測定 | 体組成の保存先の日付のノート |

### 端末ごとのもの（プラグインの設定）
次のものは端末ごと（プラグインの `data.json`）です。Obsidian Sync の「インストールされているコミュニティプラグイン」を同期していなければ、端末ごとに決めます。

- 保存先のフォルダ、記録ノートの名前、重量の単位・刻み、休憩タイマー、起動時に開く、セクションを使う
- 進行中のセット（筋トレ中の経過時間）

### 気をつけること
- **プラグインはすべての端末で同じ版に**してください。古い版の端末は、新しい版で増えた書き方（新しいカテゴリの名前・距離の列など）を正しく読めないことがあります。そのときも記録は消さず、書き込みを止めます。
- 同じセットを 2 台で同時に記録しないでください（同じノートを両方で書き換えると Sync でぶつかります）。

次は → 「ノートの形式」

## データと設定 / ノートの形式

Fitness Log のデータは、すべて vault の Markdown のノートです。手で読んだり直したり、ほかのツール（Dataview・Bases・AI エージェント）から使ったりできます。

### 記録（日ノート）
記録があった日だけ、`{記録の保存先}/YYYY-MM-DD.md` に作ります。プラグインが書き換えるのは `%% fitness-log:start %%` 〜 `%% fitness-log:end %%` の間と、frontmatter の集計キーだけです。**ブロックの外は自由に書けます**（その日の日記など）。

```markdown
---
tags:
  - fitness-log
date: 2026-10-25
packages:
  - LEGS A
exercises:
  - シーテッドカーフレイズ
  - ハンギングレッグレイズ
sets: 3
volume_kg: 150
duration_min: 1
---
%% fitness-log:start %%
## LEGS A
- 時間: 19:54:18 – 19:55:30
- コメント: スクワットはスミスマシンで
- コメント: 最後のセットは補助あり

### シーテッドカーフレイズ
| セット | 重量 (kg) | 回数 | 開始 | 終了 | コメント |
| ---: | ---: | ---: | --- | --- | --- |
| 1 | 10 | 7 | 19:54:39 | 19:54:55 | |
| 2 | 10 | 8 | 19:55:07 | 19:55:08 | |

### ハンギングレッグレイズ
| セット | 重量 (kg) | 回数 | 開始 | 終了 | コメント |
| ---: | ---: | ---: | --- | --- | --- |
| 1 | - | 12 | 19:55:09 | 19:55:11 | |
%% fitness-log:end %%

（ここから下は自由に書ける）
```

- `## パッケージ名` の下に `### 種目名` と、セットの表。単発の種目は `## その他`。
- 「時間」は筋トレを開始・終了した時刻（筋トレ中は終了が空欄）。まとめて終えたときは、そのパッケージの最後のセットの終了です。
- 「コメント」はパッケージ全体のコメントで、1 件 1 行（書いた順）。セットのコメントは表の「コメント」の列です。
- 重量は kg（設定の単位は表示だけ）。空欄は `-`。距離を記録する種目の表にだけ `距離 (km)` の列が付きます。
- 表を手で直してもよく、保存すると画面に反映されます。読めない形のときは書き込みを止めます。

### 種目
`{種目の保存先}/{種目名}.md`（1 種目 1 ノート）。

```markdown
---
aliases:
  - Yレイズ
tags:
  - fitness-exercise
fitness_id: ex_b19hcx3y
category: プッシュ
equipment: ケーブル
record_type: weight-reps
unilateral: false
archived: false
---
## フォーム
（ここから下は自由に書ける。プラグインは触らない）
```

- ファイル名 = 種目名。Properties 欄で値を変えても、ファイル名を変えても反映されます。
- `fitness_id` はパッケージとのつながりに使うので消さないでください。
- `record_type` は記録する項目（`weight`・`reps`・`distance`・`duration`）を `-` でつないだもの（例: `distance-duration`）。
- 種目フォルダに自分でノートを作ると、新しい種目として読み込みます。

### パッケージ
`{パッケージの保存先}/{パッケージ名}.md`（1 パッケージ 1 ノート）。種目・目標・区切り・ルーチンを frontmatter に書き、本文は自由なメモです。

```markdown
---
fitness_id: pk_ojhy1qnp
tags:
  - fitness-package
order: 1
exercises:
  - name: ケーブルYレイズ
    id: ex_t5oi3lo6
    sets: 2
    reps: 6-9
    rest: 150
  - name: マシンサイドレイズ
    id: ex_3cyzv8xu
    sets: 3
    reps: 6-9
    rest: 150
    note: マシン or ダンベル
routines:
  - id: rt_docs0001
    type: weekly
    weekdays: [1, 4]
    interval_weeks: 1
    start: 2026-09-01
    enabled: true
---
```

- `rest` は秒。`weekdays` は 0 = 日 … 6 = 土。
- 種目は id で指し、名前も書きます（別の端末で作った種目でも、名前でつなぎ直します）。

### 設定ノート
種目フォルダの隣の `Fitness Log 設定.md`（タグ `fitness-settings`）。カテゴリ・器具・記録のしかたの一覧と、体組成のオン/オフ・項目・目標です。最初に一覧などを変えたときに作ります。

```markdown
---
tags:
  - fitness-settings
categories: [プッシュ, プル, 脚, 肩, 腕, 体幹, 有酸素, その他]
body_composition: true
body_items:
  - name: 体重
    unit: kg
body_goals:
  - name: 体重
    target: 68
    since: 2026-07-02
---
```

### 体組成
`{体組成の保存先}/YYYY-MM-DD.md`（1 回の測定で 1 ノート）。形は 「ほかのアプリから取り込む」。

次は → 「よくある質問」

## 困ったとき / よくある質問

### 記録・種目が表示されない
- 設定の保存先と、ノートが実際にある場所がずれていないか確かめてください。ずれていると、起動時や設定を閉じたときに「ノートを移すか、保存先をノートのある場所にするか」を聞きます。
- 別の端末では、その端末の設定の保存先を見ます（保存先は端末ごとの設定です。「複数の端末で使う」）。

### 「保存先を移しますか」と聞かれた
保存先を変えた・フォルダを移したときに出ます。

- **「〇〇へ移す」**: ノートを設定の保存先へ移します（リンクも直ります）。
- **「保存先を〇〇にする」**: ノートは動かさず、設定をノートのある場所にします。

どちらか分からないときは「キャンセル」で閉じ、フォルダの中身を確かめてから選んでください。

### 「ノートを読めません」と出た
その日のノートの表を手で直したときに、読めない形（列が多い・`|` が多いなど）になると出ます。プラグインは記録を消さないよう、書き込みを止めています。通知の「ノートを開く」から表を直してください。

### 種目の名前を変えたら、過去の記録はどうなる？
つながったままです。前の名前は種目の「別名」に残り、過去の記録はその名前で見つけます。

### 種目を削除したら、過去の記録は？
残ります。種目のノートはゴミ箱へ移りますが、記録（日ノート）はそのままで、ログにも残ります。

### 古い版の端末で「書き込めません」と出る
新しい版で増えた書き方（距離の列など）を、古い版は知らないので書き込みを止めています。すべての端末を同じ版に更新してください。

### 体組成のページが出ない
設定 → 体組成 →「体組成を記録する」がオンか確かめてください。オンにすると ☰ のメニューに「体組成」が出ます。

### 体組成のノートを入れたのに出ない
- 保存先（設定 → 体組成の保存先）の中にあるか、名前が日付（`2026-10-22.md`）か確かめてください。
- 値が数字か（`66.7` であって `"66.7 kg"` ではない）確かめてください。形は 「ほかのアプリから取り込む」。

### 体組成の目標のバーが空のまま
目標を決めた日の値から、まだ動いていない（または目標から離れた）ときは空です。次の測定で目標に近づくと伸びます（「体組成」）。

### データはどこにある？外に送っている？
すべて vault の中のノートと、プラグインの設定（`data.json`）です。インターネットに通信するのは、最初の設定の「使い方の動画」を再生したときだけです。
