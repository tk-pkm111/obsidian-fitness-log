## 書き方
- Obsidian の書き方で書く: ページへのリンクは `[[ページ名]]`、画像は `![[名前.png|360]]`（スマホの画面は幅 360、PC の画面は 720 くらい）。各ページの最後に「次は → [[…]]」。
- ページの名前（ファイル名）がそのまま Publish のタイトルになるので、本文に `#` の見出しは書かない。節は `##`。
- 文言は画面と同じ言葉にする（ボタンの名前は **太字**）。アドバイス（「次は何 kg」など）は書かない。
- 個人の記録・体組成の値・本番の vault のフォルダ名は載せない（画像も作りもののデータで撮る）。
- ページを足したら `scripts/docs-guide.mjs` の `PAGES` にも足す。

## 画像を撮り直す
画面を変えたら撮り直す。

```bash
npm run docs:shots
```

一時フォルダに撮影用の vault（最初の設定の例・ダミーの記録・ダミーの体組成）を作り、隔離した Obsidian をスマホの幅・ダークで開いて、`docs/guide/images/` に 26 枚撮る（`scripts/docs-shots.mjs`）。ボタンの文言を変えたら、スクリプトの場面の操作も直す。

## エージェントに渡す
```bash
npm run docs:bundle
```

全ページを 1 つにまとめた `docs/fitness-log-guide.md` を作る（直接は編集しない）。GitHub の URL を渡せば、どのエージェントにも読ませられる。

## Publish へ移す
```bash
npm run docs:export -- "<vault>/<Publish 用のフォルダ>/Fitness Log"
```

ページ（章のフォルダごと）と画像を書き出す（上書きするだけで、ほかのファイルは消さない）。そのあと Obsidian で「Publish changes」を押す。
